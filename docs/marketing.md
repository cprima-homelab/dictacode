## Product Roadmap

### 🛹 MVP “Single Mode”
- 1 Pi5 + 1 Pi Zero
- 1 PC, 1 USB keyboard device
- Types what you speak, locally
- No cloud, no accounts, no panel
- Works by config files + terminal tools

### 🚲 “Multi-Keyboard Mode”
- 1 Pi5 + many Pi Zero keyboards
- 1 active keyboard at a time
- Plug into different PCs, rotate desks
- Same local rules, same accuracy
- No audio sharing between devices
- Toggle active keyboard by config

### 🚗 “Profiles & Comfort”
- Microphone profiles (easy select)
- Rugged build guides (BYO hardware)
- Panel stays optional, local-first
- FOSS multipliers: stars, donations, contributions

### ✈️ “Local AI Keyboard Platform”
- Multiple keyboards registry
- Safe switching (only 1 types)
- Drop-in for AI pair coding, offline sites, private desks
- Packaging + docs for easy reuse
- One brain, one typer, many plugs, local always
